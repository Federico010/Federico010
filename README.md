# Federico Urbini

**Robotics · Perception · Control · Autonomous Systems**

M.Sc. student in Artificial Intelligence and Robotics at Sapienza University of Rome. My work focuses on perception and control for autonomous robots in uncertain environments.

## Selected Projects

- **Human–robot handovers · Thales Alenia Space:** Developing a ROS 2 framework for dynamic object handovers with RGB-D hand tracking, Kalman-based state estimation, short-horizon motion prediction, and adaptive handover targets.
- **Free-floating space robotics · ESA Academy GRASP:** Contributed to a ROS 2 perception and control stack with stereo target localization and trajectory generation based on the Generalized Jacobian; supported hardware testing at ESA ESTEC.
- **Mobile manipulation and HRI:** Built a ROS 2 architecture for a simulated mobile manipulator integrating open-vocabulary 3D perception, VLM-based task planning, SLAM/Nav2 navigation, grasping, and multimodal interaction.
- **Autonomous-driving perception:** Developed a model-agnostic pipeline using semantic segmentation outputs to detect unknown road obstacles.
